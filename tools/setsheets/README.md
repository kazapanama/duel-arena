# 🖼️ Скіни через OpenAI Images API

Кожен скін — аркуш деталей (шолом, тулуб, низ броні, наплічник, пряма рука, пряма нога, зброя, плащ) у напівоберті 3/4,
який потім ріжеться на растрові деталі й збирається на ригу гри (`js/cutout.js`).

## Процес

1. **Вибір сетів** — `tools/picker/picks.json` (по 3 сети на спек; обиралку прибрано — вибір зроблено).
2. **Завдання** — `python tools/setsheets/build_jobs.py`:
   - `jobs.json` — 90 завдань (спек × слот): сет, раса, зброя спеку;
   - `refs/<id>.png` — скріншот сету з `_refs/picker/img/` (обрізаний до портрета, збільшений);
   - `prompts/<id>.txt` — промпт із `template.txt`;
   Расу чи зброю окремого скіну міняємо в `OVERRIDES` у `build_jobs.py`.
3. **Генерація** — `python tools/setsheets/gen.py` (див. довідку у файлі):
   Image 1 = `layout_template.png` (сітка й «привиди» деталей), Image 2 = реф сету. Результат — `out/<id>.png`.
   Ключ — змінна `OPENAI_API_KEY` або файл `tools/setsheets/.openai_key` (у `.gitignore`).
4. **Перевірка** — `gen.py --review` → `out/_review.png`. Якщо бракує деталі — `gen.py --only <id> --part shoulder`.
5. **Нарізка й пакування** — `slice.py` (сітку шукає сам; `--auto назва=x,y`, якщо генератор зсунув клітинки),
   `pack_cutout.py <набір> --auto` (точки кріплення рахуються самі) → `img/cutout/<набір>.js`.

## Скріншоти сетів

`tools/picker/build_catalog.py` бере головний скріншот сторінки сету на Wowhead (WotLK Classic).
Невдалі (таурени, крихітні фігури, ефекти, ракурс збоку) замінено вручну з усіх скріншотів сету, його варіантів
і трансмог-сетів сучасної бази: `tools/picker/candidates.py <id сету>` → контактні листи в `_refs/picker/cand/`,
`candidates.py --use <id сету> <id скріншота>` ставить вибраний, `--tm <id сету>=<id трансмог-сету>` — ще одне джерело.

## Вартість (`gpt-image-2.5-sunburst`, high, 1536×1024)

≈ $0.07 за аркуш (оцінка: текст ~1300 токенів, 2 референси, вихід ~1372 токени).
Усі 90 з першої спроби ≈ $6.5; з повторами й домальовуванням деталей — орієнтовно $15–20.
Точні токени й ціна кожного виклику — `out/<id>.json` і `out/ledger.csv`.
