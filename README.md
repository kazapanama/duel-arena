# Азерот Арена

Піксельний 2D-файтинг у браузері за мотивами World of Warcraft (WotLK 3.3.5): 10 класів × 3 спеціалізації, у кожної свої здібності й ультимейт, 14 арен. Можна битися з ботом (швидкий бій, аркада, виживання, тренування), удвох на одній клавіатурі чи геймпадах або по Wi-Fi з двох телефонів.

**▶ Грати: [kazapanama.github.io/duel-arena](https://kazapanama.github.io/duel-arena/)** — нічого встановлювати не треба, працює й на телефоні.

## Режими

Меню **«Один гравець»**:

- **Швидкий бій** — один матч проти бота. Складність — у налаштуваннях (легко / нормально / важко).
- **Аркада** — сім суперників поспіль (різні класи, випадкові арени), складність росте з кожним боєм, останній — бос зі збільшеним здоров'ям і шкодою. Поразку можна «продовжити» — це рахується в підсумку.
- **Виживання** — безкінечна серія з одного раунду на бій. Здоров'я між боями майже не відновлюється (+300, не менше 350), суперники з кожною хвилею сильнішають. Рекорд зберігається.
- **Тренування** — манекен (стоїть, блокує або б'є у відповідь), без таймера й раундів. У паузі — «Ресурси»: без відкатів чи ще й без шкоди. На екрані — таблиця шкоди за здібностями: сума, DPS, найбільший удар.
- **Статистика** — перемоги й поразки за кожним спеком, ★ за пройдену аркаду, рекорди. Зберігається в браузері (`localStorage`).

## Застосунок (PWA)

Сайт можна встановити як застосунок: у Chrome/Edge — «Встановити» в налаштуваннях гри чи в меню браузера, на iPhone й iPad — «Поділитися» → «На початковий екран». Гра відкривається на весь екран у альбомній орієнтації й працює без мережі.

Службовий скрипт `sw.js` кешує все, що гравець бачив. Код і розмітку (`index.html`, `js/*`, `css/*`) бере з мережі з перевіркою ETag — тож оновлення на GitHub Pages видно одразу, а без мережі береться кешована копія. Важкі файли (картинки, шрифти, набори деталей бійців) віддає з кешу миттєво й оновлює у фоні. Версії вручну вести не треба. Локально (`localhost`) service worker вимкнено, щоб правки не губилися в кеші; перевірити можна з `?pwa` в адресі.

Іконки (`img/pwa/`) генерує `python tools/pwa_icons.py` з піксельних `img/vs.svg` і `img/felflame.svg`.

## Запуск локально

Потрібен [Node.js](https://nodejs.org) 18+. Пакети встановлювати не треба.

```sh
npm start        # на Windows можна просто двічі клікнути server.cmd
```

Гра відкриється на `http://localhost:8080`. Інший порт: `node tools/server.js 8081`.

### Гра по мережі

На сайті цього режиму нема, лише через локальний сервер.

1. Запусти сервер, як вище. Він виведе адресу для телефона, наприклад `http://192.168.1.23:8080`.
2. Відкрий її на двох пристроях в одній Wi-Fi мережі.
3. Обидва гравці обирають у меню **«Гра по мережі»**. Хто зайшов першим, той обирає арену.

> Якщо телефон не відкриває адресу, перевір, чи брандмауер Windows пускає `node`, і чи не ввімкнена на роутері ізоляція клієнтів (так буває в гостьових мережах).
