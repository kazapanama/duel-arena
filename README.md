# Азерот Арена

Піксельний 2D-файтинг у браузері за мотивами World of Warcraft (Wrath of the Lich King 3.3.5). Без рушіїв, збирачів і залежностей: чистий HTML, CSS і JavaScript на `<canvas>`.

**▶ Грати: [kazapanama.github.io/duel-arena](https://kazapanama.github.io/duel-arena/)** — у браузері на ПК чи телефоні, нічого встановлювати не треба.

- 10 класів × 3 спеціалізації, у кожної свої здібності — лише такі, що були в WotLK 3.3.5; у спеку три скіни за мотивами тір-сетів і арена-сетів.
- Бійці зібрані з піксельних деталей обладунку на скелеті з IK: анімації ключовими кадрами, напівоберт 3/4, палітра сету й контур.
- Бойова модель із замахом, парируванням, шкалою захисту, хітстопом і стагером, комбо зі скасуванням легкого удару важким.
- Сила дій: звичайна (X, B, A) < сильна (Y, касти й канали) < ультимейт. Удар збиває замах, каст чи ульту лише тоді, коли він не слабший за них; слабший тільки ранить, а каст відсувається.
- Супершкала й свій ультимейт для кожного спеку: Bladestorm, Shockwave, Divine Shield, Killing Spree, Hex, Mirror Image, Metamorphosis, Starfall…
- Форми друїда: кіт, сова й дерево життя. Пети (вовки, гуль, фелгард, інфернал) — піксельні моделі на тих самих скелетах; у них є здоровʼя, їх можна вбити. Пастки мисливця, тотеми шамана.
- 14 піксельних арен: Наґранд, Блейдс-Едж, Руїни Лордерону, Каналізація Даларану, Кільце Звитяги, Гурубаші, брами столиць та інші.
- Режими: бій із ботом (3 рівні складності), двоє на одній клавіатурі чи геймпадах, **гра по мережі** на двох пристроях.
- На телефоні з'являється сенсорне керування.

## Запуск

**Один пристрій.** Відкрий [сайт гри](https://kazapanama.github.io/duel-arena/) або локально `index.html` у браузері.

**По мережі.** На сайті мережевої гри нема — вона йде через локальний сервер. Потрібен [Node.js](https://nodejs.org) 18+, встановлювати пакети не треба:

```sh
npm start              # або: node tools/server.js [порт], на Windows — server.cmd
```

Сервер покаже адресу на зразок `http://192.168.1.23:8080`. Відкрий її на телефоні в тій самій Wi-Fi мережі. Щоб грати удвох, обидва гравці обирають у меню **«Гра по мережі»**. Хто зайшов першим, стає хостом.

> Якщо телефон не відкриває адресу, перевір, що брандмауер пускає `node` у цій мережі і що на роутері вимкнена ізоляція клієнтів (буває в гостьових Wi-Fi).

## Керування

| | Гравець 1 | Гравець 2 | Геймпад | Телефон |
|---|---|---|---|---|
| Рух / стрибок | `A` `D` / `W` | `←` `→` / `↑` | хрестовина, стік | стік зліва |
| Блок (вчасно — парирування) | `S` | `↓` | L1 | стік униз або кнопка «Блок» |
| Здібності 1–4 | `J` `K` `L` `U` | `Num1`–`Num4` | X Y B A | кнопки справа |
| Форма друїда | `I` | `Num5` | R1 | кнопка «Форма» |
| Ультимейт (повна шкала) | `O` | `Num6` / `[` | R2 | кнопка «Ульта» |
| Пауза | `Esc` | | Start | `II` вгорі |

Комбо: влучив легким ударом — одразу тисни сильний, він вийде без глобального КД і встигне, поки суперник не оговтався.

## Іконки

Іконки здібностей і класів лежать у `img/icons/`: це оригінальні іконки WoW, перемальовані в піксель-арт гри через OpenAI Images API (`tools/icons/stylize.py`). Шляхи всередині — такі самі, як у наборі **WoW Icon Pack**, з якого вони зроблені.

Відповідність «здібність → файл» задана в `js/data.js` (`ABILITY_ICONS`, `CLASS_ICONS`, `SPEC_ICONS`, `FORM_ICONS`, `ic` в `ULTS`).

Нова іконка: поклади оригінал у `WoW Icon Pack/` (його в репозиторії нема; оригінал з Wowhead — `python tools/fetch_icon.py <назва іконки>`), пропиши шлях у `js/data.js` і запусти `python tools/icons/stylize.py` — він перемалює лише ті, яких ще нема в `img/icons/`.

Поки іконку не перемальовано, в `img/icons/` можна покласти оригінал і дописати його шлях у `img/icons/_raw.txt`: гра покаже оригінал, а `stylize.py` перемалює його при наступному запуску й викреслить зі списку.

## Структура

| Шлях | Що там |
|---|---|
| `index.html`, `css/style.css` | екрани й інтерфейс |
| `js/core.js` | константи, стан, полотно |
| `js/data.js` | класи, спеки, здібності, скіни |
| `js/rig.js`, `js/cat.js` | скелет і анімації (гуманоїд, кіт) |
| `js/paint.js`, `js/models.js` | частини моделей і опис сетів |
| `js/sprite.js` | піксельний конвеєр спрайтів |
| `js/fighter.js`, `js/game.js` | боєць, бій, ультимейти, HUD |
| `js/pets.js`, `js/projectiles.js`, `js/arena.js` | пети, піксельні снаряди й предмети з неба, фони арен |
| `js/ui.js`, `js/menubg.js` | меню, вибір бійця, фон |
| `js/input.js`, `js/touch.js` | клавіатура, геймпади, сенсорне керування |
| `js/net.js`, `tools/server.js` | гра по мережі: клієнт і сервер (статика + WebSocket) |
| `gallery.html` | спрайт-шит будь-якого скіну (`?skin=rogue/Assassination/2`) і сітка всіх (`?mode=all`) |
| `tools/balance.py`, `tools/sim.js` | турнір ботів для перевірки балансу (Python + Playwright) |
| `ROADMAP.md` | що ще хочеться зробити |

### Як влаштована гра по мережі

Хост рахує бій як зазвичай і щокадру надсилає гостю знімок усього, що малюється (зазвичай 1–3 КБ). Гість нічого не рахує: малює знімки й шле свій ввід. Розсинхрону бути не може, а гість грає із затримкою на передачу по Wi-Fi і назад. Сервер лише пересилає повідомлення між двома гравцями.

## Баланс

```sh
pip install playwright
python tools/balance.py 3 2            # раундів на пару, складність ботів 0–2
python tools/balance.py 8 2 priest     # лише пари з указаними спеками
```
